# Дистанционная приёмка — Магнит

Статическая production-сборка для размещения в GitHub/GitHub Pages. Серверная часть для работы интерфейса не требуется: логика чек-листа, темы и формирование Excel работают в браузере.

## v64

- отключено автоматическое сворачивание разделов после заполнения на 100%;
- чек-лист, карточки товаров, данные поставки и итоговые массы остаются открытыми после завершения;
- ручное сворачивание через кнопку «Свернуть» сохранено;
- обновлена версия статических ресурсов до `v64`, чтобы браузер и GitHub Pages не использовали старый кэш.

## v62

- исправлена отсутствующая переменная акцентного цвета `--accent` в библиотеке тем;
- исправлены адаптивность и масштабирование окна тем на desktop, tablet и mobile;
- устранены переполнения карточек тем, полей настройки, preview и footer при узких окнах и browser zoom;

- архив очищен от локального сервера, launcher-файлов, старых Excel-шаблонов, дублей библиотек/логотипов и служебных заметок.

## Публикация на GitHub Pages

Загрузите содержимое этой папки в корень репозитория. В Settings → Pages выберите Deploy from a branch и папку `/ (root)`. Главная страница — `index.html`.

## Основные файлы

- `index.html` — интерфейс;
- `styles.css` — основной дизайн и адаптивность;
- `theme-studio.js` — библиотека и настройки тем;
- `app.js` — логика приложения;
- `template-data.js`, `old-template-data.js` — встроенные Excel-шаблоны;
- `vendor/exceljs.min.js` — формирование Excel в браузере;
- `vendor/jszip.min.js` — очистка персональных свойств готового Excel;
- `assets/` — логотипы и иконки.
